# 板级联调清单

1. 下载最小 HDMI 测试图 bitstream，显示器应锁定 640×480@60 Hz。
2. 检查 HDMI-B：D2=E1/D1、D1=F1/F2、D0=G5/G6、CLK=C3/C2；确认显示器 HPD=J6 有效。
3. 运行 SDRAM 参考工程，确认初始化完成和连续读写均正常。
4. 插入 FAT32 TF 卡；无卡时必须保持 HDMI 输出并显示错误提示。
5. 依次验证 `PIC0001.BMP`、`PIC0002.BMP` 的读取、按键切换、自动轮播、暂停和特效。
6. 验证 `AUD0001.WAV` 的 HDMI 音频与 8 段音频电平条。
7. 拔掉电脑 USB 数据连接后重新上电，确认系统仅靠板载 TF、按键与 HDMI 独立运行。
